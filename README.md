# 简历工坊

一个基于原生 HTML、CSS 和 JavaScript 的网页版简历生成器。用户可以编辑简历内容、管理简历模块、上传图标，并将成品导出为 PDF。

## 功能

- 个人信息、教育背景、实习经历、项目经历、荣誉奖项、专业技能编辑
- 主模块添加、删除和恢复
- 每个经历模块支持添加和删除多个子项目
- 学校图标、公司图标和项目图标本地上传与移除
- 右侧 A4 简历实时预览
- 浏览器本地保存简历内容
- 使用浏览器直接导出 PDF
- 支持响应式页面和打印样式

## 项目结构

```text
resume-generator/
├─ index.html       页面结构
├─ styles.css       页面样式、响应式布局和打印样式
├─ app.js           简历数据、编辑交互、本地存储和 PDF 导出
├─ README.md        项目说明
└─ .gitignore       Git 忽略规则
```

## 如何运行

这是一个纯静态项目，不需要安装依赖或启动后端服务。

### 直接打开

双击 `index.html`，或将它拖入浏览器即可使用。

### 使用 VS Code Live Server

安装 Live Server 扩展后，右键 `index.html`，选择 **Open with Live Server**。常见访问地址为：

```text
http://127.0.0.1:5500/index.html
```

端口由 Live Server 决定，如果该端口被占用，扩展会使用其他可用端口。本项目自身不监听固定端口。

## 数据保存

简历数据保存在当前浏览器的 `localStorage` 中，键名为 `resume-studio-data`，包括：

- 文本内容
- 模块和子项目结构
- 上传图片的 Base64 数据

数据只保存在当前浏览器和设备中，不会自动同步到其他浏览器或设备。清除浏览器站点数据会删除已保存的简历内容。

## PDF 导出

预览区可以选择 `A4`、`Letter` 或 `Legal` 纸张大小，并可勾选 **一页适配**。一页适配会将整份简历按比例缩放到一张纸内，适合希望导出单页简历的场景；取消后会按所选纸张正常分页。

点击页面右上角的 **导出 PDF** 按钮即可下载 PDF。项目通过 CDN 加载 `html2pdf.js`；一页适配模式会使用画布整体缩放，普通模式使用 html2pdf 分页导出。如果 CDN 不可用，会回退到浏览器打印流程。

## 开发说明

- 修改页面结构时编辑 `index.html`
- 修改视觉样式时编辑 `styles.css`
- 修改数据模型、交互逻辑或导出逻辑时编辑 `app.js`
- 修改后刷新浏览器页面即可查看效果
